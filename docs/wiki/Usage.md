# 사용법

[홈](https://github.com/Taeksu0710/zoomtrans/wiki) · [설치](https://github.com/Taeksu0710/zoomtrans/wiki/Installation) · [문제 해결](https://github.com/Taeksu0710/zoomtrans/wiki/Troubleshooting)

## 회의 시작

1. Ollama가 실행 중인지 확인하고 ZoomTrans를 엽니다.
2. 시작 준비 창에 누락 항목이 나오면 설치·다운로드한 뒤 **다시 확인**을 누릅니다.
3. **스피커로 듣기** 또는 **무음 · 자막만**을 선택합니다.
4. 회의나 강의 소리를 재생합니다. 영어 원문이 표시되고 번역이 완료되면 한국어가 나타납니다.

스피커 모드는 현재 출력과 BlackHole을 함께 사용하도록 전환합니다. 무음 모드는 시스템 소리를 BlackHole로 보내므로 Mac에서 재생하는 소리가 들리지 않을 수 있습니다. 정상 종료하면 원래 출력으로 복원합니다.

## 화면 조작

![작은 자막 창](https://raw.githubusercontent.com/Taeksu0710/zoomtrans/main/docs/images/compact-light.png)

| 조작 | 동작 |
| --- | --- |
| **기록** / ⌘⇧H | 작은 자막 창과 최근 100개 발화 기록 전환 |
| **화면 고정** / ⌘⇧F | 현재 화면만 고정. 음성인식·번역·회의록 저장은 계속 진행 |
| **최신으로** | 위로 스크롤한 기록에서 최신 자막 위치로 이동 |
| **설정** / ⌘, | 화면 표시와 이번 실행의 12B 옵션 조절 |
| **종료** / ⌘Q | 남은 발화·번역 처리와 저장을 마친 뒤 종료 |

단축키는 앱에 포커스가 있을 때 동작합니다. 제목 영역을 끌면 이동하고, 창 가장자리를 끌면 크기를 바꿀 수 있습니다. 기록 화면은 현재 회의의 최근 발화를 보여주며, 전체 회의록은 파일에 저장합니다.

화면을 고정하면 새 발화 수가 표시됩니다. 고정을 해제하거나 **최신으로**를 선택하면 실시간 위치로 돌아갑니다.

## 표시 설정

![자막 설정](https://raw.githubusercontent.com/Taeksu0710/zoomtrans/main/docs/images/settings-light.png)

| 설정 | 적용 방식 |
| --- | --- |
| 한국어 글자 크기 | 16–32pt, 즉시 적용·저장 |
| 배경 불투명도 | 65–100%, 글자 자체는 흐려지지 않음 |
| 영어 원문 함께 표시 | 즉시 적용·저장 |
| 다른 창 위에 표시 | 즉시 적용·저장 |
| 긴 문장·복합 조건문에 12B 사용 | 다음 번역 작업부터 적용, 이번 실행에만 유지 |

화면 설정과 창 위치·크기는 다음 실행에도 유지됩니다. 밝은·어두운 색상은 시스템 설정을 따릅니다. 12B의 준비와 적용 기준은 [모델과 번역 설정](https://github.com/Taeksu0710/zoomtrans/wiki/Models-and-Translation)을 참고하세요.

## 회의 종료와 요약

**종료**를 선택하면 남은 음성과 번역을 처리하고 회의록 저장을 마칩니다. 저장할 대화가 있으면 요약 생성 여부를 선택할 수 있습니다. 요약에는 회의 개요, 주요 논의, 결정 사항, 액션 아이템을 정리합니다.

종료 중에는 작업이 끝날 때까지 기다려 주세요. 강제 종료하면 출력 장치 복원이나 마지막 기록 저장을 마치지 못할 수 있습니다. [복원 방법](https://github.com/Taeksu0710/zoomtrans/wiki/Troubleshooting)을 참고하세요.

## 저장 파일

| 실행 방식 | 기본 위치 |
| --- | --- |
| 다운로드 앱 | `~/Library/Application Support/ZoomTrans/logs` |
| 소스 실행 | 실행 위치의 `logs/` |

- 회의록: `meeting_날짜_시간.txt`
- 요약을 선택한 경우: 회의록 옆의 `meeting_날짜_시간_summary.txt`
- 처리 시간 진단: `meeting_날짜_시간_performance.jsonl`

원문·번역과 선택한 요약은 로컬 파일에 저장됩니다. 오디오 녹음 파일은 만들지 않습니다. 진단 JSONL에는 원문·번역 대신 처리 시간과 모델 등 운영 정보를 기록합니다. 파일을 공유하기 전에 내용을 확인하세요.
