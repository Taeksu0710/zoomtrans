# 모델과 번역 설정

[홈](https://github.com/Taeksu0710/zoomtrans/wiki) · [설치](https://github.com/Taeksu0710/zoomtrans/wiki/Installation) · [문제 해결](https://github.com/Taeksu0710/zoomtrans/wiki/Troubleshooting)

## 기본 구성

| 역할 | 기본 모델 | 준비 |
| --- | --- | --- |
| 음성인식 | `mlx-community/whisper-large-v3-mlx` | 시작 준비 창의 다운로드 버튼 |
| 한국어 번역 | `gemma4:e4b` | `ollama pull gemma4:e4b` |
| 선택적 복잡한 문장 번역 | `gemma4:12b` | `ollama pull gemma4:12b` |

일반 실행에서는 기본 번역 모델만 사용하고 예열합니다. 12B를 설치해도 옵션을 켜지 않으면 번역에 사용하지 않습니다.

## 12B 옵션

**설정 → 긴 문장·복합 조건문에 12B 사용**을 켜면 다음 원문에 보조 모델을 사용합니다.

- 원문이 **40단어 이상**인 경우.
- 조건 표현 `if`, `unless`, `provided that`과 시간 표현 `until`, `before`, `after`가 함께 있는 경우.

두 조건 중 하나만 충족해도 적용합니다. 이는 원문 규칙에 따른 선택이며 별도의 모델 판별 요청은 보내지 않습니다. 나머지 문장은 기본 모델로 번역합니다.

| 상황 | 동작 |
| --- | --- |
| 일반 앱 실행 | 옵션 꺼짐 |
| 실행 중 켜거나 끔 | 다음 작업을 시작할 때 새 설정 적용 |
| 이미 번역 중인 문장 | 처음 선택한 모델로 번역·재시도 완료 |
| 대기 중인 문장 | 실제 작업 시작 시의 설정 적용 |
| 창을 닫았다가 설정을 다시 열기 | 같은 실행의 선택 유지 |
| 앱을 다음에 일반 실행 | 다시 꺼짐 |
| 12B가 없거나 번역 실패 | 화면에 알리고 기본 모델로 대체 |

실행 중 옵션을 켜면 첫 해당 문장에서 모델 준비 시간이 추가될 수 있습니다. 12B는 속도보다 복잡한 조건·시간 관계의 의미 보존을 개선하기 위한 선택입니다. 더 높은 정확도를 항상 보장하지는 않습니다.

## 문장 연결과 대화 문맥

오디오 입력 → Whisper 인식 → 문장 확정·번역 대기열 → Ollama 번역 → 자막·회의록 순서로 처리합니다.

- 실제 오디오에서 약 0.6초 침묵이 감지되면 인식합니다. 미완성 구절은 다음 구절을 기다리며, 추가 음성이 없으면 1.2초 침묵에서 확정합니다.
- 긴 발화는 8초부터 4초 간격으로 확인하고, 완료된 문장만 먼저 번역합니다. 시간만으로 문장 중간을 확정하지 않습니다.
- 인식 오디오가 28초에 이르면 단어 경계에서 인식 창을 옮깁니다. 미완성 원문은 보관해 다음 음성과 연결합니다.
- 직전 6개 발화의 원문과 가능한 번역을 합계 4,000자까지 참고합니다. 한국어 발화와 번역에 실패한 원문도 문맥에 남습니다.
- 두 번역 모델은 같은 문맥을 공유합니다. 확정 문장은 순서대로 처리하며 앞 문장을 건너뛰지 않습니다.
- 한국어는 생성이 끝난 뒤 표시합니다. 길이 제한에 걸리면 한 번 더 긴 생성으로 재시도하며, 미완성 번역은 표시·저장하지 않습니다.

문장 경계는 규칙과 인식 결과를 사용하므로 긴 문장이 묶이거나 잘못 나뉠 수 있습니다. 상태 표시의 문장 수집·다음 구절 대기·번역 대기 수를 함께 확인하세요.

## 지연을 줄이고 싶다면

먼저 12B를 끄고 기본 모델로 비교하세요. 문장 수집 시간 외에도 Whisper 계산, Ollama 생성, 앞 작업의 큐 대기가 추가됩니다. 긴 문장이 앞에 있으면 뒤의 짧은 문장도 기다립니다.

작은 Whisper를 시험하려면 다음처럼 실행합니다. 선택한 모델의 다운로드가 별도로 필요합니다.

```sh
/Applications/zoomtrans.app/Contents/MacOS/zoomtrans --whisper-model small
```

## CLI에서 모델 지정

```sh
# 이번 실행에 선택적 12B를 활성화. UI에서도 변경 가능
/Applications/zoomtrans.app/Contents/MacOS/zoomtrans --complex-model gemma4:12b

# 기본 모델만 사용하도록 시작
/Applications/zoomtrans.app/Contents/MacOS/zoomtrans --complex-model none
```

소스 실행에서는 실행 파일 경로 대신 `.venv/bin/python main.py`를 사용합니다. 세부 생성 옵션과 합성 예문 비교 방법은 [번역 동작·품질 검증 문서](https://github.com/Taeksu0710/zoomtrans/blob/main/docs/translation.md)에 있습니다.
