# Contributing

See [development instructions](docs/development.md) for the clean environment,
tests and build. Open an issue before a substantial change; small fixes can be
submitted directly as pull requests.

Describe the problem, resulting behavior, and validation in each PR. Keep
translation quality changes separate from packaging changes where possible.
Use synthetic examples for tests and screenshots. Do not upload meeting
transcripts, recordings, model weights, credentials or local diagnostic logs.

Contributions are provided under this project's MIT license. Third-party
dependencies retain their own licenses.
